# Sai Venkat Boyapati — Portfolio

Personal portfolio website built with React + TypeScript + Vite + Framer Motion + fullpage.js

## Tech Stack
- React 18 + TypeScript
- Vite
- Framer Motion
- fullpage.js (horizontal scroll)
- DM Serif Display + DM Sans + JetBrains Mono fonts

## Local Development
npm install
npm run dev

## Build
npm run build

## Live
Hosted on Vercel — auto-deploys on every push to main branch.
